# Audio-Insight-RU-

Автоматическая обработка русскоязычных аудиозаписей: транскрипция, суммаризация 
и извлечение именованных сущностей.

## О проекте

**Audio Insight RU** — веб-сервис и REST API, который принимает на вход 
аудиофайл на русском языке и возвращает:

1. **Транскрипцию** — полный текст записи.
2. **Резюме** — краткое содержание в 2–3 предложениях.
3. **Именованные сущности** — список упомянутых людей, организаций и мест.

Проект объединяет три предварительно обученные модели с Hugging Face 
в единый пайплайн. Обучение моделей не требуется.

## Применение

- **Бизнес** — протоколирование совещаний: расшифровка + резюме + список участников.
- **Медиа** — быстрая обработка интервью: расшифровка, выделение ключевых персон.
- **Образование** — конспекты лекций: текст, краткое содержание, ключевые термины.
- **Колл-центры** — анализ звонков: расшифровка, тема обращения, извлечение данных.
- **Юридическая сфера** — обработка записей заседаний: расшифровка + выделение лиц.


## Используемые модели

| Компонент | Модель | Ссылка |
|---|---|---|
| Транскрипция | `openai/whisper-small` | [Hugging Face](https://huggingface.co/openai/whisper-small) |
| Суммаризация | `cointegrated/rut5-base-absum` | [Hugging Face](https://huggingface.co/cointegrated/rut5-base-absum) |
| NER | `Gherman/bert-base-NER-Russian` | [Hugging Face](https://huggingface.co/Gherman/bert-base-NER-Russian) |

**Whisper** — мультиязычная модель ASR от OpenAI, обученная на 680 000 часов 
аудио. Поддерживает 99 языков, устойчива к шуму и акцентам.

**ruT5-absum** — русскоязычная модель суммаризации на базе ruT5. Обучена 
на датасетах Gazeta, XL-Sum и WikiLingua. Генерирует связные русские резюме.

**BERT-NER-Russian** — дообученная версия `bert-base-multilingual-cased` 
для извлечения сущностей из русского текста. Распознаёт имена, фамилии, 
отчества, страны, города, улицы, организации. F1 Score — 0.988.
